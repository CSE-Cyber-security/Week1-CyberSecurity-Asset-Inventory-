# Factorial Program (Python)

A simple Python program that finds the factorial of a number using
if / elif / else.

## Folder Contents

| File / Folder             | Description                                     |
|-----------------------------|---------------------------------------------------|
| `factorial_code.txt`        | The program code (as text).                        |
| `data.txt`                  | Sample test inputs and expected outputs.            |
| `screenshots/`              | 3 ready-made screenshots of different outputs.      |
| `README.md`                 | This file.                                          |

## How It Works

- If the number is negative → prints a message saying factorial doesn't exist.
- If the number is 0 → prints that factorial of 0 is 1.
- Otherwise → multiplies all numbers from 1 up to n to get the factorial.

## How to Run

1. Copy the code from `factorial_code.txt` into a file named `factorial.py`.
2. Run it with:
   ```
   python factorial.py
   ```
3. Enter a number when prompted.
